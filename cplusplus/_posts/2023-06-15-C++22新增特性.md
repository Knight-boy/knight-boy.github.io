## 核心语言特性

### `consteval` 放宽

C++22 放宽了 `consteval`，让编译期常量函数（`consteval`）在更多编译期求值上下文中可用，配合 `constexpr` 的放宽，常期求值能力进一步增强。

```c++
consteval int twice(int x) {
    return x * 2;
}

static_assert(twice(21) == 42, "");
```

### 常量求值增强

C++20 起允许 `constexpr` 函数使用循环与分支；C++22 继续推进常量求值能力，使 `constexpr` 函数在更多场景下可以直接参与编译期计算。

```c++
constexpr int sum_squares(int n) {
    int total = 0;
    for (int i = 1; i <= n; ++i) {
        total += i * i;
    }
    return total;
}
```

## 标准库特性

### `std::atomic` 等待能力

C++22 推进 `std::atomic` 的等待/通知能力，让原子操作支持更细粒度的时延等待。

```c++
std::atomic<int> counter{0};

counter.fetch_add(1, std::memory_order_relaxed);
counter.wait_for(std::chrono::seconds(5), std::memory_order_seq_cst);
counter.notify_all();
```

### 范围库与算法

C++22 继续打磨 `std::ranges` 与算法库，让基于范围的写法在实战中越来越顺手。

```c++
std::vector<int> v{4, 1, 3, 2};

auto m = std::ranges::max_element(v);
auto to_vec = std::ranges::to<std::vector>(v);  // 由 ranges 算法完成转换
```

## 其它

- C++22 以修复、打磨为主，新特性与 C++20/C++23 的生态（Concepts、Modules、Ranges、Coroutines）彼此推进。
- 编译器支持：gcc/clang/msvc 均已逐步支持 C++20，C++22 特性陆续进入编译器实现阶段。
