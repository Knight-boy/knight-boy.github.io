cplusplus语言特性

## 核心语言特性

### 编译期反射（Metaobject Protocol）

C++26 完成/推进编译期反射 — 程序可以在编译期以"元对象"形式查看、匹配类型、生成实例。

```c++
#include <meta>

struct Point { int x, y; };

// 编译期检查 Point 是否可用作反射元对象
auto meta = std::meta::meta_object_cast<Point>(...);
```

### 元类（Metaclass）

元类使"类型本身拥有行为"成为可能 — 类型可定义构造/复制/析构的策略。

```c++
class MyClass metaclass MyMetaObject { ... };
```

### 模块系统定稿

C++20 的 module 语法过渡期结束，`export module` 语法最终定稿，构建流程更干净、编译速度提升显著。

```c++
export module math.impl;
```

## 协程与并行

### 标准协程库

C++26 把协程从 TS/实验版推进到库标准层，提供更完整的 `co_*` 支持与类型层。

### `std::execution` 生态

执行策略（executor/thread_pool/...）继续走向库标准化，替代手写线程池。

## 常量求值增强

- `constexpr` 动态分配、virtual 成员函数等持续放宽；
- `if consteval` / 分支内的编译期评估更内建。

## 常用库

- `std::mdspan`（C++23，引用即可）；
- `std::execres` / `std::execution` 策略；
- 更新的 range 算法，支持惰性求和、扫描等。

## 其它

- 字符编码与 Unicode 统一；
- 数值计算：constexpr 数字运算库增强；
- 性能与 ABI 稳定性改进说明。
