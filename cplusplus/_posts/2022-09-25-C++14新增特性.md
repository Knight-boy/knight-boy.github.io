cplusplus语言特性

## 核心语言特性

### 函数返回类型推导

C++14 允许用 `auto` 标记函数返回类型，由函数体（return 语句）推导。推导规则与 lambda 一致。递归调用必须保证推导点已有 return 可见。

```c++
auto mul(int a, int b)
{
    return a * b;   // 返回类型推导为 int
}
```

配合尾置返回类型还可以写出 `decltype(auto)`，按 `decltype` 规则保留引用：

```c++
decltype(auto) f(int& x) { return x; }    // 返回 int&（auto 的话会推导成 int、拷贝一份）
```

### lambda 捕获的泛化（初始化捕获）

捕获列表支持初始化表达式，可以**移动语义捕获**（C++11 只能按值/按引用拷贝捕获），也可以给捕获的变量换名。被移动进闭包的成员是 `const` 的，要修改须在 lambda 上加 `mutable`。

```c++
auto p = std::make_unique<int>(42);
auto task = [ptr = std::move(p)]() { return *ptr; };   // unique_ptr 被移进闭包

auto counter = [n = 0]() mutable { return n++; };
```

### 泛型 lambda

lambda 的参数声明为 `auto` 时，相当于一个成员为模板的 operator()，同一 lambda 面对不同参数类型会实例化出不同版本。

```c++
auto add = [](auto a, auto b) { return a + b; };
add(1, 2);          // int
add(1.0, 2.0);      // double
std::string s = add(std::string("a"), "b");
```

### constexpr 放宽

C++11 的 constexpr 函数几乎只能包含一条 return。C++14 允许局部变量、循环、分支等多种语句，常规化的编写方式让 constexpr 函数可用性大幅提高。

```c++
constexpr int factorial(int n)
{
    int r = 1;
    for (int i = 2; i <= n; ++i)
        r *= i;
    return r;
}
static_assert(factorial(5) == 120, "");
```

> constexpr 不再（必须）递归 + 三目运算符拼凑逻辑。注意 constexpr 函数是否真的在编译期执行取决于传入值和上下文，编译器不必强制。

### 变量模板

变量也可以是模板，常用来表达"依类型取值"的 trait 类封装。

```c++
template <class T>
constexpr T pi = T(3.1415926535897932385L);

pi<int>      // 3
pi<double>   // 3.14159...

template <class T>
constexpr bool is_integral_v = std::is_integral<T>::value;
```

### 二进制字面量与数字分隔符

```c++
int mask = 0b1010'0001;
long  n   = 1'000'000;      // 单引号做分隔符，提高可读性，不影响数值
```

### 聚合类型允许非静态数据成员默认初始化

C++11 中类内默认初始化器会让类型失去聚合属性而不能 `= {..}` 初始化。C++14 放开：

```c++
struct Point { int x = 0; int y = 0; };
Point p{1, 2};    // C++14: OK，y 被显式给予 2；x=0 被覆盖
```

### `[[deprecated]]` 属性

```c++
[[deprecated("use g() instead")]]
void f();

[[deprecated]]
void old_api();
```

使用被标记的实体时，鼓励实现给出编译期警告。

## 标准库特性

### `std::make_unique`

补全了 C++11 的遗漏——`unique_ptr` 一直没有对应的工厂函数（`make_shared` 只服务 `shared_ptr`）。推荐用 `make_unique` 替代裸 `new`，异常安全、免写类型。

```c++
auto p = std::make_unique<std::string>("hello");
auto arr = std::make_unique<int[]>(10);
```

> C++11 时代通常自己封装 `template <class T, class... Args> std::unique_ptr<T> make_unique(Args&&...)`。

### 共享定时互斥量 `std::shared_timed_mutex`

读写锁：多个读者并发、写者独占，并支持带时限的加锁操作（try_lock_for / try_lock_until）。

```c++
std::shared_timed_mutex m;

std::shared_lock<std::shared_timed_mutex> rl(m);   // 读锁
std::unique_lock<std::shared_timed_mutex> wl(m);   // 写锁
```

### `std::integer_sequence`

编译期整数序列，常用于 tuple 的按类型/按下标展开。

```c++
template <class Tuple, std::size_t... I>
void print_impl(const Tuple& t, std::index_sequence<I...>)
{
    int unused[] = { (std::cout << std::get<I>(t) << ' ', 0)... };
    (void)unused;
}

template <class... Ts>
void print(const std::tuple<Ts...>& t)
{
    print_impl(t, std::index_sequence_for<Ts...>{});
}
```

### `std::exchange`

返回旧值并替换新值，移动赋值运算符的常见写法更省事。

```c++
int old_x = std::exchange(x, 10);
```

### `std::quoted`

流操控符，处理含空格/特殊字符的字符串加引号读写（转义、还原自动处理）。

```c++
std::cout << std::quoted("hello world");   // 输出 "hello world"
```

### chrono 字面量

`std::chrono_literals` 提供了与 `std::chrono` 配合使用的时间字面量。

```c++
using namespace std::chrono_literals;

std::this_thread::sleep_for(100ms);
auto hour = 2h + 30min;
```

### 其他

- tuple 支持**按类型取元素**：`std::get<T>(t)`。
- `std::complex` 计算、`std::swap(array, array)`、`std::rel_ops` 等标准库微调。
